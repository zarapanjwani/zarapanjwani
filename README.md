# 🚀 Featured Projects

### 🌉 Bridge The Gap *(Currently Building)*

An AI-powered career readiness platform that analyzes resumes, identifies skill gaps, and provides personalized roadmaps to help students land their first internship.

**Tech Stack:** **MongoDB • Express.js • React • Node.js (MERN) • AI**

**Tech Stack:** **MongoDB • Express.js • React • Node.js (MERN)**
